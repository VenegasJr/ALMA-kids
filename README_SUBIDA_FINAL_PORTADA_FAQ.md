# Parche final: portada + FAQ + Instagram + contacto

Este paquete consolida los cambios finales para ALMA Kids:

- Portada sin scroll forzado ni efectos pesados.
- Título: “Alma Kids: Magia en cada detalle”.
- Eliminación de “Descubre ALMA Kids” y del texto de revisión en el hero.
- FAQ responsivo con acordeones sin texto cortado.
- Botones flotantes y navegación uniforme.
- Sección Instagram preparada para datos reales mediante Netlify Function.
- Sección de contacto reformulada con enlaces funcionales.

## Estructura importante

El archivo de función debe quedar exactamente en:

`netlify/functions/instagram-profile.mjs`

No subir el ZIP directamente. Subir el contenido a la raíz de una rama nueva creada desde la rama de producción actual.
